# 📊 Product Management Dashboard

A modern, responsive, dark-themed Product Management Dashboard designed for managing inventory efficiently. Built using **HTML5**, **CSS3**, **Bootstrap 5**, and native **Vanilla JavaScript (ES6+)**.

## ✨ Features

- **Full CRUD Functionality:** Create, Read, Update, and Delete products seamlessly.
- **Data Persistence:** Uses `LocalStorage` to save data across sessions.
- **Real-Time Analytics:** Dynamically calculates:
  - Total Products Count
  - Unique Categories Count
  - Total Inventory Value ($)
- **Live Search:** Instant product filtering by name.
- **Form Validation:** Input checks with custom error alert handling.
- **Modern UI/UX:** Glassmorphism card design, dark mode palette, subtle hover animations, and fully responsive grid layout.

---

## 🛠️ Tech Stack & Skills Demonstrated

- **HTML5:** Semantic architecture (`<main>`, `<section>`, etc.) and structured form controls.
- **CSS3:** Custom CSS variables (`:root`), linear & radial gradients, glassmorphism (`backdrop-filter`), and CSS transitions.
- **Bootstrap 5:** Utility classes, responsive grid system (`col-lg-*`, `col-md-*`), and styled form controls.
- **JavaScript (ES6+):**
  - DOM Manipulation & Event Listeners
  - Array Methods & Logic Processing
  - JSON Parsing & `LocalStorage` Operations
  - Real-time filtering and dynamic table rendering
